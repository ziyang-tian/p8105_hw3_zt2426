# P8105 Homework 3

Ziyang Tian (zt2426)

This repository contains my work for P8105 Homework 3.

[View the homework report](p8105_hw3_zt2426.md)

- Problem 1: NOAA weather data, missing values, and weather plots.
- Problem 2: NHANES demographics and activity data.
- Problem 3: Citi Bike ride counts, stations, and ride durations.

Open `p8105_hw3_zt2426.Rproj` in RStudio. Then open
`p8105_hw3_zt2426.Rmd` and click Knit to create the GitHub Markdown report.

The report uses `tidyverse`, `p8105.datasets`, and `patchwork`. Rendering also
requires `knitr` and `rmarkdown`.

The local data are the two NHANES files and the four Citi Bike files supplied
with the assignment. They are stored in `data` and read using relative paths.
The NOAA data are loaded from the `p8105.datasets` package.
