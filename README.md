# P8105 Homework 3

Ziyang Tian (zt2426)

This repository is for my P8105 Homework 3. I use one R Markdown file and keep
the local data in the `data` folder.

Open `p8105_hw3_zt2426.Rproj` in RStudio. Then open
`p8105_hw3_zt2426.Rmd` and click Knit to create the GitHub Markdown report.

The local data are the two NHANES files and the four Citi Bike files supplied
with the assignment. The Citi Bike files have short names that show their
month and year. The NOAA CSV is not included. The NOAA data will be loaded from
the `p8105.datasets` package in Problem 1.
